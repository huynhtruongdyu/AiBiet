# AiBiet.Tools.Security Changelog

## v0.1.0 (2026-04-29)
- Initial release
- AI-powered security vulnerability scanning
- Supports git diff scanning, file/directory scanning
- Severity filtering and multiple output formats
- Multi-language support (C#, Java, JS/TS, Python, Go, Rust, C++, etc.)
- Smart file discovery with .gitignore support
- Binary file detection and file size limits (500KB)
- Parallel file processing with throttling (SemaphoreSlim)
- Memory-efficient string building (StringBuilder)
- Results sorted by severity (Critical > High > Medium > Low)
- Enhanced table display with separated rows
- README.md added with usage examples
- Improved AI prompt with structured output format
